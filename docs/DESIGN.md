# 设计说明（Design Notes）

> 目标：Awwwards / Webby / FWA 级别的成品感——不是「更多装饰」，而是「更少犹疑」。

## 1. 视觉定位

参照物是**公共服务站里的精致纸质文书**：温暖、可信、可长期阅读。
因此选择浅色暖灰底（`#f1f5f9`）＋ 翡翠绿主色（守护、通行）＋ 琥珀点缀（时间币的「积蓄感」），
拒绝「黑底霓虹」这类与银龄公共服务气质相悖的默认审美。

## 2. 品牌标识

`src/components/BrandMark.tsx` 为手绘矢量（非位图）：

- 外圈 = 社区守望的圆满；
- 沙漏 = 可储蓄的时间；
- 下方托举弧 = 双手相托的邻里互助；
- 顶端星芒 = 时间币的微光。

16px 下仍可辨识，支持 `tone="mono"` 单色化，用于证书、页脚等单色场景。

## 3. 版式与字阶

- 字号比例约 1.25：11 / 14 / 17 / 20 / 24 / 30px；
- 标题使用紧字距（`tracking-tight`），长句正文使用 1.75 行高；
- 数字（时间币、学时）使用 `font-black` + `tracking-tight`，形成数据锚点；
- 中文排版避免全大写英文，英文仅用于极小的辅助标签（`TIME BANK` 等）。

## 4. 动效

原则：**动效为功能服务**，只做三件事——确认操作、表达状态变化、引导视线。

| 场景 | 动效 | 时长 |
| --- | --- | --- |
| 按钮按压 | `active:scale-98` | 120ms |
| 弹层进入 | fade + 轻微上移 | 200ms |
| 卡片滚动显现 | `reveal` 上移 14px | 550ms |
| 提交成功 | 彩带 + 数字弹出 | 500ms |
| SOS | 呼吸脉冲 + 警报音 | 循环 |

全部动效遵循 `prefers-reduced-motion: reduce`，此时降级为即时显示。

## 5. 无障碍与适老化

- 触控热区 ≥ 44px（`--tap-min`），主要按钮 48px；
- 表单控件字号 ≥ 16px，避免 iOS 聚焦缩放；
- 焦点环为实色描边 `2px solid #176c69`，键盘用户始终可见；
- 「长辈大字版」一键切换 18px 正文 / 1.75 行高；
- 语音朗读（Web Speech API）用于科普与帮助中心，语速调慢至 0.95；
- 弹层具备焦点进入、循环、归还与 `Esc` 关闭，背景滚动锁定。

## 6. 空状态与异常状态

- 空列表：图标 + 说明 + 下一步建议（如「清空筛选关键词」）；
- 图片加载失败：品牌渐变占位块 + 文字说明，不出现破图；
- 页面渲染异常：全局错误边界提供「重新加载 / 恢复演示数据」两条路径；
- 本地存档损坏：静默回退默认数据，并在控制台保留告警。

## 7. 不做的事

- 不用整屏紫色渐变英雄区；
- 不用一排等宽圆角卡片配 emoji 图标堆砌「高级感」；
- 不在没有内容的地方塞大标题；
- 不让动效牺牲可读性与可操作性。
